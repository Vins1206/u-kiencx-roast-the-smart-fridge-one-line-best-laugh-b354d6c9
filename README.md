A make.fun bounty entry: one line (127 characters) roasting the smart fridge — its touchscreen died in an overnight update and is now a $3,000 whiteboard that hums and judges my leftovers.

## What it does

`main.py` (Python stdlib only) writes exactly one line of plain text, at most 160 characters, to `/output/entry.txt` — just the roast itself.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> My smart fridge updated itself overnight and now its touchscreen is just a $3,000 whiteboard that hums and judges my leftovers.
